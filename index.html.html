Automated Color Sorting Conveyor

A conveyor that reads the color of each object and sends it into the right bin by itself.

Supervised by Dr. Mohamed Elhossainy

The idea

Objects arrive one at a time on a belt. The machine stops the belt, reads the color with a color sensor, moves a servo gate to the matching bin, and counts the object. Red, green, blue and yellow go to their own bins. Anything else goes to an unknown bin.

How it works

  1. 1
    StartThe START button runs the belt.
  2. 2
    DetectAn infrared sensor sees the object and the belt stops.
  3. 3
    ReadThe TCS3200 sensor measures red, green and blue light. The color is accepted after two identical readings.
  4. 4
    RouteA servo gate moves to the bin of that color and the belt runs again.
  5. 5
    CountA sensor at the bin confirms the object arrived. The counter goes up and is saved in memory, so it survives a power cut.

Safety: STOP halts the belt, and a second press resets the counters. EMERGENCY switches everything off. If an object does not reach its bin within 5 seconds, or the temperature stays at 35 °C or more, the machine stops with an alarm.

Goals

  • Sort objects by color automatically, one at a time, without errors.
  • Keep a permanent count of every color on the display.
  • Protect the machine and the user with stop, emergency and fault states.
  • Build it in stages: simulation, 3D model, breadboard, PCB and final assembly.

Main components

ATmega32AMicrocontroller, 8 MHz crystal, programmed in C.
TCS3200Color sensor with red, green, blue and clear filters.
TCRT5000 (x6)Infrared sensors at the entry and at each bin.
L293D + DC motorDrives the belt, speed set by PWM.
SG90 servos (x2)Two gates, each sending objects to one of two bins.
LCD 20x4 (I2C)Counters, last color, temperature and status.
LM35Temperature sensor read by the on-chip ADC.
Buttons, lamps, buzzerSTART, STOP, EMERGENCY, green and red lamps, alarm.
5 V logic from an LM2596 buck · 12 V adapter · programmed with a USBasp
